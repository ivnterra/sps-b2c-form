# SPS B2C Form

Static landing page for lead collection.

## Local structure

- `index.html` - main page markup
- `css/` - modular styles (`tokens`, `base`, `layout`, `components`, `responsive`)
- `images/` - static assets

## Deploy to Vercel (Dashboard)

1. Open Vercel Dashboard and click **Add New Project**.
2. Import repository `ivnterra/sps-b2c-form`.
3. Keep default settings for a static site.
4. Confirm deployment.
5. Future pushes to `main` trigger automatic redeploys.

## Notes

- `vercel.json` enables clean URLs and disables trailing slash redirects.
- `.DS_Store` is ignored via `.gitignore`.
